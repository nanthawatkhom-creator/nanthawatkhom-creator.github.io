# แยกให้ไว ทิ้งให้ถูก! — SORT//SHIFT

เกมคัดแยกขยะภาษาไทยสำหรับบูทและกิจกรรมการเรียนรู้ ผู้เล่นลากขยะลงถังให้ตรงประเภทภายใน 75 วินาที พร้อมฝึกผ่านช่วงทดลองก่อนเริ่มเกมจริง

![ภาพหน้าเมนูเกม SORT//SHIFT](media/sort-shift-game.png)

## เล่นเกม

- [เล่นเกมออนไลน์](https://nanthawatkhom-creator.github.io/sort-shift/)
- [ดูอันดับของเครื่องนี้](https://nanthawatkhom-creator.github.io/sort-shift/leaderboard.html)

เปิดลิงก์เกมบนคอมพิวเตอร์หรือแท็บเล็ตที่มีเบราว์เซอร์สมัยใหม่ จากหน้าแรกกด **เริ่มเกม** แล้วลองแยกขยะตามประเภท เกมรองรับเมาส์และหน้าจอสัมผัส

## Leaderboard

เกมบันทึกอันดับ 50 คะแนนสูงสุดไว้ในเบราว์เซอร์ที่ใช้เล่น จึงเหมาะกับบูทที่ผู้เล่นผลัดกันเล่นบนเครื่องเดียวกัน อันดับจะแยกตามอุปกรณ์และเบราว์เซอร์

ต้องการให้อันดับและสถิติรวมกันข้ามอุปกรณ์ ให้ตั้งค่า Firebase ตาม [FIREBASE_SETUP.md](FIREBASE_SETUP.md) ก่อน โดยสร้าง Firebase Web App, เปิด Firestore, วาง Web App config ใน `js/firebase-config.js`, เปิด `FIREBASE_ENABLED` และเผยแพร่ Firestore rules จาก `firestore.rules` ไฟล์ตั้งค่าปัจจุบันยังปิดโหมดออนไลน์ไว้

## เปิดใช้ที่บูท

1. ต่อคอมพิวเตอร์เข้าจอหรือโปรเจกเตอร์ และเปิดลิงก์เกมด้านบนใน Chrome หรือ Edge
2. กด `F11` เพื่อขยายเต็มหน้าจอ หากใช้จอสัมผัสให้เปิดเกมในโหมดเต็มหน้าจอของเบราว์เซอร์
3. กดเริ่มเกม แล้วให้ผู้เล่นลากขยะลงถังทั้ง 4 ประเภท
4. หลังจบรอบ เกมจะแสดงผลและอันดับของเครื่องนั้น

เมื่อไม่มีอินเทอร์เน็ต ให้ใช้ `RUN_GAME.cmd` บน Windows แล้วเปิดเกมที่ `http://127.0.0.1:8080/index.html` เกมใช้ CDN สำหรับ Phaser, Howler และฟอนต์ จึงต้องเชื่อมอินเทอร์เน็ตเพื่อโหลดไลบรารีและเสียงครบถ้วน แม้เปิดเว็บจากเครื่องที่รันเกมในเครือข่ายท้องถิ่น

## รายละเอียด

- เกม HTML/CSS/JavaScript ใช้ Phaser 3 และ Howler.js
- รองรับเมาส์และสัมผัส พร้อมบทสอนก่อนจับเวลา
- เนื้อหาเชื่อมโยง SDG 12 และ SDG 13
- เว็บเผยแพร่ด้วย GitHub Pages ที่ `/sort-shift/`
